## Objective
This repo contains the full collection of work perfomed by Judit (JMW) in the Keller
lab 2020-2025

The repo is organized into folders - many of which are their own git hub repos
(organized as subrepositories)

### Subfolders:
- **dissertation**
This folder contains drafts, documents and forms related to the qualifying exam and 
dissertation. Also subfolders for posters and presentations, grants and applications
JMW been involved in. For documentation in box only, the complete folder is under gitignore)
- **fe_si_images** 
This repo contains scripts, metadata files etc for all feline small intestinal
images (WSIs)for the Keller lab. 
- **fe_si_models** 
This repo contains folders with documentation etc for models used to process
feline small intestinal biopsies

- **svm_archives**
This repo contains script and files for archives at UC Davis School of Veterinary medicine
containing feline small intestinal biopsies or records (labl & vmacs)
- **fe_si_samples**
This repo contains all samples (organized by folder) that JMW has been involved in 
sampling for the Keller lab as well as collaborating labs. 

- **fe_si_platforms**
This repo contains scripts etc for AI platforms used to process images/data

- **fe_si_papers** 
This repo contains folders for papers (finished and in progress) that JMW has 
been involved with for the keller lab. 
-**sample_size**
Minifolder with strategy for calculating sample size for performance assessment

### Organization of subfolders
Most subfolders are organized with the following folders:
- **scripts**: 
Most Rmd scripts are organized with a first chunk containing directories, libraries 
and functions, and subsequent chunks containing documented 
implementations of the functions.
- **output**:
Organized by script name.
- **input**
Input files for all scripts in folder (unless from other subfolder,
where to find input files are documented in each script)
- **historic** contains previous versions kept for documentation (not currently
in use)
