## Objective
Contains drafts, figures and supplemental for the paper, submissions, and 
communicaitons associated with the submissions. All under gitignore.

### Folders
- **communications**: Vet path correspondence
- **figures**: A subfolder per figure - each with adobe illustrator version (editable),
pptx (if applicable) as well as png (300 dpi for publication). 
Also a subfolder for "historic" (previous versions, not included in paper).
- **previous_revisions**: Dump of previous versions, w dates and intials
- **submissions**: Contains a subfolder for each vetpath submissions with 
associated material
- **supplemental**: Contains supplemental material (and subfolder "historic" 
for previous versions)
